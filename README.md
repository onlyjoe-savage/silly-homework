# Oak & Ember Interiors — Furniture Website Assignment

## Project files
- `index.html` — Home
- `about.html` — About
- `products.html` — Products (six items with prices)
- `categories.html` — Categories (four categories)
- `gallery.html` — Gallery
- `contact.html` — Contact information and demo contact form
- `images/README.md` — image folder notes

## Run locally
Open `index.html` in a browser while connected to the internet. Tailwind CSS v4 Browser CDN and the furniture photos are loaded online.

## Tailwind CSS
Every page loads Tailwind CSS v4 with:
`https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4`

The custom brand theme is defined with `@theme` in each page's `<style type="text/tailwindcss">` section:
- `oak`
- `oak-light`
- `sand`
- `cream`
- `ink`

## Before submitting
1. Replace sample phone/address/email details in `contact.html` if your lecturer expects real details.
2. Test all six pages and every navigation link.
3. Images use online Unsplash image URLs, so an internet connection is required. The `images/` folder is included for any locally saved images you decide to add.
4. The contact form is a front-end demo only; it displays a message but does not send email.
5. Push the folder to your own public GitHub repository and deploy the same repository to GitHub Pages, Vercel and Netlify.
6. Use your actual live URLs in the LMS submission. Do not submit example or invented deployment links.
